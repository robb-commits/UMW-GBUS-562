# UMW-GBUS-562
Repository for GBUS 562 (AI Language Models)


## About

This repository contains materials created for GBUS 562: AI Language Models at the University of Mary Washington (UMW). The materials are organized into weekly folders, one for each week of the course.

## Weekly Work

1. Week 1: an AI-coded [Connect 4 game](week-01/connect-4.html), built with Claude Code, with three computer difficulty levels and an optional two-player mode.
